7-Zip LZ4 26.05.2，基于官方 7-Zip 26.05，新增多语言 Windows 安装版。

- Windows 安装版和便携版包含官方全部 **93 个语言资源**，支持简体中文、繁体中文等；可在“工具 → 选项 → 语言”中切换。
- 安装向导支持英文、简体中文、繁体中文，按 Windows 界面语言自动选择，无需先弹语言选择框。
- 安装时可选 **7-Zip 原生右键菜单**、`.lz4/.lz4l`“打开方式”和桌面快捷方式，支持自定义安装目录。
- 完整包含 `7zz.exe`、`7za.exe`、`7z.exe`、`7z.dll`、`7zFM.exe`、`7zG.exe`、`7-zip.dll`，保留 LZ4 压缩、解压及文件关联列表。
- 升级时不关闭资源管理器；若 DLL 被占用，将按提示在重启后完成替换。
- 安装器、语言资源、来源校验信息、更新日志与自动化验证均已纳入仓库。

下载：

- `7z-lz4-26.05.2-x64-setup.exe`：Windows x64 **安装版**，需要管理员权限。
- `7zip-26.05.2-lz4-windows-x64.zip`：Windows x64 便携版。
- `7zip-26.05.2-lz4-linux-x64.tar.gz`：Linux x64 `7zz` 命令行版。
- `7zip-26.05.2-lz4-source.tar.gz`：对应源码，含语言资源和安装脚本。
- `SHA256SUMS.txt`：以上四个文件的 SHA-256 校验和。

Windows 11 的原生右键扩展可能显示在“显示更多选项”中。旧 MiMo 26.04.2 安装版请先卸载再安装本版。此为未签名的 KartNid 定制构建；原生 shell CLSID 与官方 7-Zip 共用，一次只能由一个安装目录拥有右键集成。

标准 `.lz4` 文件可与普通 LZ4 工具互通；`7zz a -m0=LZ4 archive.7z input` 创建的 7z 文件需要本构建或兼容编解码器才能解压。Linux 控制台输出保留上游英文消息。详细说明见仓库 `docs/windows-install.md`，历史见 `CHANGELOG.txt`。
