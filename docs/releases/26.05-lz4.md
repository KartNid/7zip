7-Zip 26.05 with the `lz4-support` branch merged into `main`.

- Create and extract standard `.lz4` frame files, including concatenated and skippable frames.
- Use LZ4 inside 7z archives: `7zz a -m0=LZ4 archive.7z input`.
- Include the branch's Windows file-association and program-location fixes.
- Build Windows x64 binaries with MSVC and the Linux x64 console with GCC.
- Validate LZ4 round trips, interoperability with an independent LZ4 library, truncated/corrupt input rejection, six existing archive formats, and encrypted 7z before publication.

Downloads:

- `7zip-26.05-lz4-windows-x64.zip`: portable `7zz.exe`, `7z.exe`, `7z.dll`, `7zFM.exe`, `7zG.exe`, and `7-zip.dll`. Extract the whole ZIP into one folder. Binaries are unsigned; no installer or automatic shell registration is included.
- `7zip-26.05-lz4-linux-x64.tar.gz`: standalone `7zz` console, built on Ubuntu 22.04.
- `7zip-26.05-lz4-source.tar.gz`: exact release sources.
- `SHA256SUMS.txt`: SHA-256 checksums for all three archives.

This is a custom KartNid build. Upstream 7-Zip does not include this LZ4 codec; recipients need this build or a compatible codec to open 7z archives using LZ4. Standard `.lz4` files remain interoperable with normal LZ4 tools.
